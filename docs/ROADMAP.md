# 路线图

## M0 技术验证

**目标**：逐个证明风险点能用 Go 打通，决定是否继续。结论是继续，见 [技术选型](TECH_CHOICES.md)。

- [x] 仓库骨架：GPL-3.0、Go module、`make check`、CI
- [x] BLE 连通：purego 绑定 CoreBluetooth，找到系统已连接的 RC003，订阅 ATVV
- [x] ADPCM 解码：`internal/atvv`，测试数据与 open-voice-bridge 对照，真机音频人耳确认
- [x] 写入 BlackHole：按 UID 找设备，AudioQueue 播放 16 kHz PCM，由系统重采样
- [x] Fn 点按与 F5 屏蔽：只屏蔽 RC003 的 F5，CGEvent 模拟 Fn，Typeless 能被开始和结束
- [x] 聚集设备：解决 Typeless 看不到 BlackHole 的问题
- [x] MyGo 外壳：打包成 `.app`，蓝牙授权、连接遥控器、按住说话出字

## M1 语音输入

**目标**：不懂技术的用户装好后，按住遥控器说话就能出字。

### 设备和音频

- [x] 设备层：`Device` 接口、统一事件、TOML 设备描述
- [x] RC003 适配器：识别、语音会话、断线自动重连、读电量和型号
- [x] 自动创建聚集设备 `yaozhi-mic`（只含 BlackHole 2ch，固定 UID，缺了就重建）
- [x] 音量增益 0–20 dB、实时电平
- [x] 空闲时停掉 AudioQueue，设备检查改为监听系统通知（空闲 CPU 约 0.1%）

### 语音会话

- [x] 输入法预设（TOML），内置 Typeless
- [x] 开头缓存、误触过滤（不足 150 ms）、末帧淡出、连按排队、断线照样结束
- [x] 没有辅助功能时不开始语音，"收尾中"8 秒兜底回到空闲
- [ ] 电源键映射为 F20
- [ ] 评估能否缩短结尾等待（目前松键后约 430 ms 结束）

### 界面

- [x] "墨与朱"界面：概览、语音、按键（预览）、设备四页，跟随系统深浅色（设计稿 [`design/index.html`](design/index.html)）
- [x] 菜单栏：系统菜单，四种图标状态（平时、正在听、已暂停、需要处理），暂停和启用
- [x] 首次引导：概览页就是五步清单，最后一步在遥指自己的输入框里出字才算完成
- [x] 权限和就绪检测：蓝牙、BlackHole、Typeless 安装和运行、辅助功能（每 2 秒）
- [x] 版本信息、关于面板、导出诊断
- [ ] 在界面里切换输入法预设（目前只能用 `-preset` 启动参数）
- [ ] 小尺寸（32 px 以下）的简化 App 图标；用 Icon Composer 做支持深色和着色的分层图标

### 发布

- [x] 本机签名：`yaozhi-dev` 自签名证书，重新编译不用重新授权
- [x] GitHub Actions 打包 dmg：推送 `v*` 标签时用自签名证书 `Yaozhi Release` 签名，上传到草稿 Release（`.github/workflows/release.yml`；签名和打包在本机验证过，还没在 GitHub 上跑过）
- [ ] 生成发布证书并存进 Secrets，推送仓库，发第一个 Release，在另一台 Mac 上验证下载、放行和升级后授权保留
- [ ] Developer ID 签名和公证（加入 Apple 开发者计划后），用户不用再手动放行

### 验收

- [ ] 真机连续 20 次按住说话都能出字，开头和结尾不丢字
- [ ] Mac 睡眠唤醒、开关蓝牙、遥控器断线后都能自动恢复；说话中途断线时 Typeless 被正确结束
- [ ] 在一台全新的 Mac 上从零走完首次引导：蓝牙询问出现在点"继续"之后，没装 BlackHole 或 Typeless 时能发现并引导安装
- [ ] 系统重启后 `yaozhi-mic` 重建，Typeless 仍能选到
- [ ] 增益配合 Typeless 的识别效果；深色外观、关于面板、导出诊断在真机上检查过

## M2 控制 Mac

**目标**：遥控器的每个键都能自定义，用来控制 Mac 和切换应用。

- [ ] 读取遥控器按键，尽量独占设备，不影响其他键盘
- [ ] 识别单击、双击、长按，按住时连续触发
- [ ] 动作库：按键、快捷键录制、媒体键、打开 App、切换应用
- [ ] "按键"页：矢量遥控器设置界面，按下实体键时实时高亮
- [ ] 按当前 App 自动切换键位方案；配置导入导出
- [ ] 申请"输入监控"权限；权限被撤销时立即拆掉按键监听，避免卡住整机输入

## M3 更多设备

**目标**：验证设备适配层，接入第二款遥控器。

- [ ] 第二款设备：优先选同样走 ATVV 的遥控器（如 Chromecast 语音遥控器、小米蓝牙遥控器 2 非 Pro），只加设备描述、不改代码
- [ ] 设备选择界面
- [ ] 第二个"虚拟麦克风 + 快捷键"类输入法预设（如 Handy）

## 以后再考虑

- 遥指自己识别语音再输入文字（本地模型或云端接口）。这会改变"遥指不做语音识别"的定位，M1 只在输入法层留了接口。

## 不做

- 打包、修改或重命名 BlackHole，或写驱动安装脚本
- 修改系统默认的输入和输出设备
- 豆包输入法（它会隐藏虚拟音频设备）
- 运行时加载插件代码（设备和输入法差异都用数据文件描述）
