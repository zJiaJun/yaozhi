冷启动：概览页就是引导

不另做向导窗口。还没准备好时，概览页的大标题写“还差几步”，下面按顺序列出五件事：做完的打勾，当前这一步展开，写清楚要做什么并给出按钮。五步都完成后，这一列换回平时的样子。上面的主窗口可以用“冷启动”那排按钮逐步查看。

1 连接遥控器先说明用途，点“继续”才触发系统的蓝牙询问。没配对的，告诉他同时长按主页键和菜单键，并给“打开蓝牙设置”。
2 安装 BlackHole 2ch没装时给出 brew install blackhole-2ch 和“复制命令”，另有“打开下载页”给不用 Homebrew 的人。装好后遥指自己发现，并创建 yaozhi-mic，不用再点。
3 安装 Typeless没装时给 brew install typeless 和“复制命令”，另有“打开 Typeless 官网”；装了没开时按钮变成“打开 Typeless”。遥指按应用标识判断，名字和网址写在输入法预设里。
4 允许辅助功能说明只替你点 Fn，按钮“去授权”，沿用现在的授权引导。
5 选麦克风，说一句提示在 Typeless 的“选择麦克风”里选 yaozhi-mic，然后直接在这一步里的输入框说一句。出字了，就全部完成。
完成第 5 步出字后不马上换页：标题变成“准备好了。”，五步全打勾，刚说的那句话留在框里，下面一句说明和“开始使用”。点了才换成平时的概览页，那里没有输入框。

试一试：在遥指里看到出字

冷启动的第 5 步里有一个输入框。光标默认就在这个框里，按住语音键说一句，文字直接落在这里，不用切到别的 App 去验证。出字了，这一步才算完成。平时的概览页不放这个框，保持标题、波形和统计。下面是它的四种状态。

图标

一支斜着的遥控器，同时也是一根伸出去的手指。朱砂色的圆点是语音键，指尖前的两道弧是"遥"。小尺寸时去掉圆环和外弧，只留机身、红点和一道弧。
