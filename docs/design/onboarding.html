虚拟声卡

安装 BlackHole 2ch

遥指把遥控器的声音写进开源的虚拟声卡 BlackHole，输入法再从这里收音。它需要你自己装一次原版；装好之后的事遥指会自动处理，不改你的系统默认麦克风。

BlackHole 2ch在终端运行下面的命令安装，装好后遥指会自动发现
brew install blackhole-2ch
已经装过 BlackHole 的话，向导会直接跳过这一步。
允许模拟按键

让遥指替你点 Fn

Typeless 用 Fn 开始和结束听写。遥指要在你按住、松开语音键时替你点一下 Fn，这需要"辅助功能"权限。遥指只发 Fn，不读取你的其他按键。

辅助功能打开系统设置后，把 Yaozhi 拖进列表

在 Typeless 里选 yaozhi-mic

打开 Typeless 的设置，把麦克风选为 yaozhi-mic，快捷键保持 Fn。遥指看不到 Typeless 的设置，选好后点"我选好了"，下一步说一句话来确认。
